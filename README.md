# Material-Review-Assistant

素材审核助手，接入豆包 2.0 Pro 大模型，帮助广告从业者审核投放素材，支持图片、视频素材批量智能审核。

## ✨ 功能特性
- **批量图片审核**：支持自定义审核标准，批量上传图片进行合规审核
- **批量视频审核**：支持自定义审核标准，批量上传视频进行合规审核
- **结果与数据看板**：右侧展示实时审核结果、历史审核记录，内置统计仪表盘，支持筛选通过 / 不通过素材
- **一键导出报告**：审核结束后快速导出审核报告，便于归档复盘
